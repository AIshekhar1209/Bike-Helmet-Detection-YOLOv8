# 🚴 AI-Based Bike Helmet Detection Using YOLOv8

An AI-powered Computer Vision project designed to detect motorcycle riders with and without helmets using the YOLOv8 object detection framework.

## 📌 Project Overview

Road safety is an important concern, especially for two-wheeler riders. This project focuses on detecting helmet usage through computer vision and deep learning techniques.

The system analyzes images and videos to identify helmet-related objects and display detection results using bounding boxes.

## 🎯 Objectives

- Detect riders wearing helmets.
- Identify riders not wearing helmets.
- Apply YOLOv8 for object detection.
- Explore real-world testing of helmet detection.
- Develop a practical AI-based road safety application.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/AIshekhar1209/Bike-Helmet-Detection-YOLOv8.git
```

Move into the project directory:

```bash
cd Bike-Helmet-Detection-YOLOv8
```

Install dependencies:

```bash
pip install -r requirements.txt
```
